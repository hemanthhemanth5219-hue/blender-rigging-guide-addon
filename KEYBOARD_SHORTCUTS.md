# Blender Keyboard Shortcuts & Rigging Addon Guide

## Essential Blender Shortcuts for Rigging

### Navigation & Selection

| Shortcut | Action |
|----------|--------|
| `Right Click` | Select object/element |
| `A` | Select All |
| `Alt+A` | Deselect All |
| `Box Select` | `B` - Draw box around elements |
| `Circle Select` | `C` - Paint circular selection |
| `Lasso Select` | `Shift+F` - Free-form selection |
| `Alt+Click` | Select edge loops |
| `Shift+Click` | Add to selection |
| `Middle Mouse` | Rotate view |
| `Scroll Wheel` | Zoom in/out |
| `Shift+Scroll` | Pan view |
| `Numpad 7` | Top view |
| `Numpad 1` | Front view |
| `Numpad 3` | Side view |
| `Numpad 0` | Camera view |

### Mode Switching

| Shortcut | Action |
|----------|--------|
| `Tab` | Toggle Edit/Object Mode |
| `Ctrl+Tab` | Toggle Pose Mode |
| `Z` | Shade Mode Menu |
| `Z + Z` | Wireframe Toggle |
| `Z + S` | Solid Mode |
| `Z + M` | Material Preview |

### Transformations

| Shortcut | Action |

| `Z` | Constrain to Z-axis |
| `Shift+Z` | Constrain to XY-plane |
| `Alt+R` | Clear Rotation |
| `Alt+G` | Clear Location |
| `Alt+S` | Clear Scale |

#### Quick Start (5 minutes)

1. **Press `N`** to open the sidebar
2. **Look for "Rigging Guide"** tab
3. **Select guide type**: Basic, Advanced, or Facial
4. **Read Step 1** description and tips
5. **Follow the instructions** step by step
